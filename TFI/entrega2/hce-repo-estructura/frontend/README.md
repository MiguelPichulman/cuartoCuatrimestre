# Frontend

Vistas Thymeleaf y assets estáticos (CSS/JS/Bootstrap) del proyecto.

Se completa a partir de la etapa de implementación, una vez aprobado el diseño (esta entrega
es solo de análisis y diseño). La organización prevista, según `docs/arquitectura-proyecto.md`,
es una carpeta de templates por módulo funcional (guardia, internacion, diagnostico,
evolucion, medicacion, permisos, egreso), más una carpeta común para layout/fragments
compartidos (header, nav, footer) y `static/` para CSS/JS/Bootstrap.
